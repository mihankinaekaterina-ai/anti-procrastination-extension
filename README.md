# Таймер прокрастинации — Анти-пожиратель времени

Небольшое браузерное расширение для Google Chrome на Manifest V3. Оно временно перенаправляет пользователя с отвлекающих сайтов на страницу с коротким заданием. После выполнения задания доступ к сайтам открывается на выбранное время.

## Возможности

- Блокировка переходов на YouTube, Instagram, TikTok, Twitch и VK.
- Три вида заданий на выбор:
  - прочитать короткую страницу документации;
  - решить простой вопрос по JavaScript;
  - написать одну строку JavaScript-кода.
- Для задания с кодом проверяется строка `console.log("Привет, мир!");` (также принимается вариант с одинарными кавычками и без точки с запятой).
- После выполнения задания сайты разблокируются на 5, 10, 15 или 30 минут.
- Настройки, количество выполненных заданий и суммарное время отдыха сохраняются локально.
- После окончания таймера блокировка включается автоматически.
- Исходный адрес сайта сохраняется, чтобы после выполнения задания вернуться туда, куда пользователь пытался перейти.

## Установка в Google Chrome

1. Скачайте ZIP-архив и распакуйте его в отдельную папку.
2. Откройте в Chrome страницу `chrome://extensions/`.
3. Включите переключатель **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `anti-procrastination-extension`, в которой находится `manifest.json`.
6. Закрепите расширение на панели браузера и откройте его настройки.
7. Выберите подходящие задания и продолжительность доступа, затем нажмите **Сохранить настройки**.
8. Откройте YouTube или другой сайт из списка блокировки для проверки.

## Как проверить задания

- **Прочитать материал:** откройте ссылку на MDN, вернитесь на страницу расширения и нажмите кнопку выполнения.
- **Решить задачу:** выберите ответ `8` для выражения `2 + 3 * 2`.
- **Написать код:** введите `console.log("Привет, мир!");` и нажмите кнопку выполнения.

## Структура проекта

- `manifest.json` — настройки расширения и разрешения Chrome.
- `service-worker.js` — блокировка сайтов, таймер доступа и сохранение статистики.
- `blocked.html`, `blocked.css`, `blocked.js` — страница задания, которая показывается вместо отвлекающего сайта.
- `popup.html`, `popup.css`, `popup.js` — окно настроек и статистики.

## Ограничения текущей версии

- Выполнение задания на чтение подтверждается пользователем самостоятельно.
- Код проверяется по одному простому шаблону; это учебная проверка, а не полноценный анализ программы.
- Список блокируемых сайтов задан в коде и пока не редактируется в интерфейсе.
- Расширение рассчитано на браузеры на базе Chromium, поддерживающие Manifest V3 и указанные API.
- Как и любое обычное расширение, его можно отключить в настройках браузера. Цель проекта — помочь соблюдать собственное правило, а не обеспечить принудительную блокировку.

## Используемые технологии

HTML, CSS, JavaScript (без сторонних библиотек), Chrome Extension API, Manifest V3 и `chrome.storage.local`.
